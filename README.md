# 辽·卷 — 指尖上的辽宁

> 2026 年（第五届）辽宁省大学生国潮文化设计应用比赛 · **C 类 动态产品设计（H5 互动产品）** 参赛作品
>
> 主题：**传承 · 智绘 · 融合** ｜ 维度：**辽风 · 辽景 · 辽韵 · 辽味**

一幅可以在手机上滑动展开的国潮数字长卷。观者依次剪一扇满族窗花、游辽宁四景、拨动一台皮影、集齐辽味四宝，再沿辽史长河、群英、百工、矿珍、社火、方言、古塔、十四市、墨宝、脸谱、山珍一路走过，让**「智绘」端上算法**为自己即兴生成一枚国潮诗签，最终生成一张带着自己"游印"的**专属国潮明信片**，一键保存分享——把一次浏览变成一次可传播的关外之旅。全程还有 AI 智游助手**「卷灵」**随行答疑、带你直达任意一章。

二十枚游印实时记录游历进度，进度存入 `localStorage`，中途退出可续玩。印章体系为**数据驱动 + 章节自注册**：顶部紧凑进度药丸「印 N / 总」、细进度条、终章明信片印墙（自动多行排布，20 枚恰成两行）、集齐礼花均随印章数量自动适配，新增章节无需改动任何全局文件。

全程右下角常驻 AI 智游助手**「卷灵」**：点击展开对话，基于内置知识库 + 关键词规则引擎回答关于各章与辽宁文化的问题，并能「带我去」任意一章——纯前端、离线可用。

## 二、技术栈与架构

- **纯前端单页**：Vite + 原生 JavaScript（ES Module）+ CSS 动画 + Canvas，无后端、无框架运行时。
- **章节自注册架构**：每个章节是一个自包含的 `src/chapters/<name>.chapter.js`——自建 section DOM（`html` 字符串）、`import` 自己的 CSS、在描述符里声明印章与需持久化的 state 字段。`main.js` 用 `import.meta.glob('./chapters/*.chapter.js', { eager:true })` 自动装载全部章节，按 `order` 排序插入到终章之前并逐个 `init`。**新增/改章节 = 只动自己那两三个文件，零冲突可多人并行开发。** 契约样板见 `src/chapters/_TEMPLATE.chapter.txt`。
- **零图片程序化美术**：`src/art.js` 提供剪纸、山河、人物、非遗、矿石、秧歌等 canvas 矢量绘制；新章（辽塔、脸谱、山珍、星空、墨宝、智绘诗签等）在各自模块内 canvas/SVG 自绘，零新增图片。
- **端上「智绘」智能**：智绘诗签用「模板 + 主题词库 + 加权随机」的确定性生成算法即时拼出对仗押韵的国潮诗联；AI 智游助手「卷灵」是内置知识库 + 关键词规则引擎。二者**均离线运行、不调用云端大模型**，如实标注为端上算法。
- **零外部依赖运行**：音效由 Web Audio 实时合成（锣、弹拨、五声音阶），无音频文件；网络字体非阻塞加载，断网自动回退系统宋体。
- **Canvas**：多章刮开/描红互动 + 智绘诗签（720×1080）+ 明信片（1080×1920）合成导出。
- **移动端优先**：`100dvh` 全屏分章、`scroll-snap` 逐屏、Pointer Events 统一触摸/鼠标手势。
- **包体**：构建产物 JS ≈ 101KB（gzip ≈ 36KB）+ CSS ≈ 58KB（gzip ≈ 11.5KB），22 屏零新增图片，扫码秒开。

## 二·五、AI 与融合（「智绘」创新点 + 诚信标注）

紧扣大赛主题「传承 · 智绘 · 融合」，本作品的「智绘」全部为**可离线运行的端上智能**，并如实标注、不夸大：

| 能力 | 实现 | 诚信标注 |
| --- | --- | --- |
| 智绘诗签（辽智章） | 模板 + 主题词库 + 加权随机的确定性生成算法，对仗成联、押韵配横批与祝福，多次生成不重复 | **端上算法即时生成，非云端大模型**；章内「这是 AI 吗？ⓘ」浮层如实说明 |
| 卷灵 · 智游助手 | 内置知识库 + 关键词规则引擎，答疑并「带我去」任意章节 | 纯前端规则引擎，离线可用，不联网 |
| 后 13 章视觉 | canvas / SVG 程序化自绘 | 完全自绘，零新增图片、无 AI 生成图 |
| 内置 7 章插画 | AI 图像生成 + 人工二次加工 | 已在《作品说明》如实标注 AI 辅助 |

> **合规**：C 类未禁止 AI；本作品全程走文化通识 + 程序化生成路线，**未对辽宁"六地红色文化"作任何 AI 生成式阐释**（E 类禁区），规避风险。

## 四、部署 + 生成二维码（提交用）

C 类作品提交格式为**二维码或 MP4**。推荐把 `dist/` 部署到任一免费静态托管，拿到公网网址后生成二维码贴进报名表。

**方式 A：Vercel（最简单）**
1. 把项目推到 GitHub 仓库。
2. 登录 vercel.com → New Project → 选择该仓库 → 一路默认（Vercel 自动识别 Vite）→ Deploy。
3. 得到形如 `https://xxx.vercel.app` 的网址。

**方式 B：GitHub Pages**
1. 推到 GitHub 仓库。
2. `npm run build`，将 `dist/` 内容推到 `gh-pages` 分支（或用 GitHub Actions）。
3. 仓库 Settings → Pages 选中该分支，得到 `https://用户名.github.io/仓库名/`。
   （`vite.config.js` 已设 `base:'./'`，子路径部署无需改配置。）

**生成二维码**：把公网网址粘贴到任意二维码工具（草料二维码 cli.im、或在线 QR generator）导出高清 PNG，放进报名表。建议二维码下方标注"请用手机浏览器扫码，横竖屏均可，建议开启声音"。

## 五、录制 MP4 备用版（应对现场无网）

比赛要求短视频：**竖屏 9:16、时长 ≤ 60 秒、MP4 / H.264、≤ 100MB**。

1. 手机浏览器打开作品，用系统"屏幕录制"完整走一遍五章（约 50–60 秒）。
2. 或电脑上用 Chrome 手机模拟（F12 → 设备工具栏 → 选 iPhone 尺寸）+ OBS 录制竖屏区域。
3. 用剪映/PR 裁成 9:16、导出 H.264 MP4，压到 100MB 以内。

### 如何再加一章（自注册）

1. 复制 `src/chapters/_TEMPLATE.chapter.txt` 为 `src/chapters/<name>.chapter.js`，新建同名 `<name>.css`。
2. 在 `registerChapter({ id, order, seal, state, className, html, init })` 里填好该章的 DOM 与逻辑。
3. 完成——`main.js` 会自动装载、排序、插入到终章前并初始化；HUD、明信片印墙、集齐礼花全部自动适配。无需改动任何全局文件。
