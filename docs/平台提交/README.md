1. 从组委会 / 平台「资源下载」获取附件 1、附件 2，核对文件名后上传。
2. 将简介字段与实施方案粘贴到平台对应编辑区（管理员权限）。
3. 确认「高校审核推荐时间 2025→2026」是否由官方更正后再改平台正文。
4. 本队参赛材料（作品二维码/MP4、盖章报名表等）按 C 类要求另行准备——见仓库根目录 `README.md`。
